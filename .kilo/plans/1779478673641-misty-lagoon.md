# Fix Plan: LSTM Collapse + Goal Position Mismatch

## Problem Summary

1. **Goal Position Mismatch**: The agent's observation always encodes the goal at `(2.0, 0.0)` regardless of where the actual goal marker and barrier gap are in the world file. Worlds 5–8 shift the goal to different Y positions, but the agent never knows about this.

2. **LSTM Collapse**: After the first collision in harder worlds, the LSTM enters a death spiral — steering develops a persistent left bias, collisions compound, and the agent never recovers. Root causes: 33% more parameters than GRU (catastrophic interference), architecture-blind entropy decay (too aggressive for LSTM), broken entropy computation (noisy Monte Carlo estimate), and gradient monitoring gaps.

---

## Fix 1: Goal Position Mismatch

### 1.1 Read Goal Position from World File at Reset

**File**: `controllers/Webots/webots_env.py`

**Location**: `WebotsEnv.__init__()` and `WebotsEnv.reset()`

**Change**: After the environment initializes, read the `GOAL_MARKER` position from the Webots world file and update `self._endpoint` to match.

```python
# In __init__, after self.robot is created:
self._sync_endpoint_from_world()

def _sync_endpoint_from_world(self):
    """Read GOAL_MARKER position from world file and update self._endpoint."""
    goal_node = self.robot.supervisor.getFromDef("GOAL_MARKER")
    if goal_node is not None:
        translation = goal_node.getField("translation").getSFVec3f()
        goal_xy = np.array([translation[0], translation[1]], dtype=np.float32)
        self._endpoint = goal_xy
        self.reward_computer.endpoint = tuple(goal_xy.tolist())
        start_xy = np.array(self.config.start_position[:2], dtype=np.float32)
        self._reference_distance = float(np.linalg.norm(start_xy - goal_xy))
```

**Rationale**: Every training world has a `DEF GOAL_MARKER Solid` with `translation` set to the correct goal position. Reading it directly avoids any dependency on barrier geometry constants.

### 1.2 Update Reference Distance

After updating `self._endpoint`, also update `self._reference_distance`:

```python
start_xy = np.array(self.config.start_position[:2], dtype=np.float32)
self._reference_distance = float(np.linalg.norm(start_xy - self._endpoint))
```

### 1.3 Verify Reward Computer Sync

Ensure `self.reward_computer.endpoint` is updated alongside `self._endpoint`.

## Fix 2: LSTM Collapse

### 2.1 Fix Entropy Computation (Analytical Formula)

**File**: `controllers/PPO/PPO.py`

**Location**: `evaluate_sequences()` method, lines ~409–414

**Current (broken)**:
```python
entropy_pre_tanh = dist.rsample()
entropy_action_tanh = torch.tanh(entropy_pre_tanh)
entropy = dist.log_prob(entropy_pre_tanh)
entropy -= torch.log(self.action_scale + 1e-6)
entropy -= torch.log(1.0 - entropy_action_tanh.pow(2) + 1e-6)
entropy = -entropy.sum(dim=-1)
```

**Replace with analytical entropy of Normal distribution**:
```python
# Analytical entropy: 0.5 * D * (1 + log(2*pi)) + sum(log(std))
analytical_entropy = 0.5 * self.action_dim * (1.0 + math.log(2 * math.pi)) + self.actor_log_std.sum()
entropy = analytical_entropy.expand(batch_size, seq_len)
```

**Rationale**: Removes stochastic noise from the entropy gradient, stabilizing training for all architectures.

### 2.2 Architecture-Aware Entropy Coefficient

**File**: `controllers/PPO/PPO.py`

**Location**: Entropy decay logic, lines ~631–632

**Current**:
```python
decay_frac = min(1.0, episode / max(1, config.episodes))
agent.config.entropy_coef = d.PPODefaults.entropy_coef * (1.0 - 0.60 * decay_frac)
```

**Replace with**:
```python
decay_frac = min(1.0, episode / max(1, config.episodes))
# Scale initial entropy by architecture parameter count
arch_scale = {"none": 1.0, "gru": 1.0, "lstm": 1.35}[self.config.recurrent_cell]
base_entropy = d.PPODefaults.entropy_coef * arch_scale
# Gentler decay: 1.0 -> 0.70 (instead of 1.0 -> 0.40)
agent.config.entropy_coef = base_entropy * (1.0 - 0.30 * decay_frac)
```

**Rationale**: LSTM gets 35% more initial entropy to match its larger parameter count, and the decay is gentler (only 30% reduction vs. 60%) to prevent premature convergence.

**File**: `controllers/PPO/PPO.py`

# Log recurrent core gradient norm for diagnostics
if rnn_attr is not None:

### 2.4 State-Dependent Log Std (Optional, Higher Risk)

**File**: `controllers/RNN/base.py` and subclass files

**Concept**: Replace the global `actor_log_std` parameter with a small network that predicts log_std from the recurrent hidden state. This allows the policy to modulate its stochasticity based on context (e.g., be more cautious near obstacles).

**Risk**: This changes the policy architecture and may require retraining from scratch. Recommend implementing only if fixes 2.1–2.3 are insufficient.

1. **Fix 1.1–1.3** (Goal position sync) — Critical, high confidence
2. **Fix 2.1** (Analytical entropy) — Low risk, benefits all architectures
3. **Fix 2.2** (Architecture-aware entropy) — Medium risk, directly addresses LSTM collapse
4. **Fix 2.3** (RNN gradient logging) — Diagnostic only, no behavioral change
5. **Fix 2.4** (State-dependent log std) — Defer unless needed

3. Compare LSTM stability metrics: actor_loss, grad_norm, policy_entropy across runs
4. Confirm LSTM no longer collapses after first collision in harder worlds
5. Compare final performance (avg10 reward, success rate) across architectures
